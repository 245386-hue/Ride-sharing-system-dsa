# Ride-Sharing System (Mini-Uber)

A console-based C++ ride-sharing application simulating an Uber-like system with driver/rider management, ride booking, ride assignment, and analytics.

## Features
- Multi-role system (Admin, Driver, Rider)
- Vehicle types: Bike, Car, AC Car, SUV
- Ride booking and assignment
- Ride cancellation and completion
- Driver rating system
- Analytics and report generation
- Sorting and searching algorithms

## Technologies Used
- C++
- File Handling
- Data Structures & Algorithms

## Data Structures Implemented
- Map
- Queue
- Stack
- Vector

## Algorithms Used
- Bubble Sort
- Merge Sort
- Quick Sort
- Linear Search
- Binary Search

## Pricing Formula
Fare = (Base Fare + Distance × Per KM Rate) × Vehicle Multiplier
